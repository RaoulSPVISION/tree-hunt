# The Great Christmas Tree Hunt — Phase 1

## Put it on your phone (GitHub Pages)
1. Create a new GitHub repository (e.g. `tree-hunt`).
2. Upload all files from this folder: index.html, sw.js, manifest.json, icon-192.png, icon-512.png.
3. Settings → Pages → Deploy from branch → main / root → Save.
4. Open the Pages link in Chrome on your phone → ⋮ menu → "Add to Home screen" / "Install app".
5. Open it once while online; after that it works with no signal.

## Updating later
Upload the new index.html, then change VERSION at the top of sw.js (e.g. v1.0.1) so phones pick up the update.

## Your data
Saved on the phone automatically. Settings → "Save a backup file" now and then.
"Restore or merge a backup" merges trees without duplicates — that is also how a second phone can be combined.
